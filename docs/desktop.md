# TodoList 桌面版

在 Windows 双击 `TodoList.exe` 打开专注工作台。源码也可以通过 `python main.py desktop` 启动。回到主窗口时，顶部会询问当前任务的进展，可选择已完成、切换其他任务、补充进展或继续执行。宽窗口右侧显示任务切换时间线，缩窄窗口后可在任务列表旁的「切换历史」标签查看。置顶悬浮窗可拖动，并可直接完成当前任务、恢复上一项或切换任务。

可从右上角或任务列表上方新增任务，弹窗在按钮附近打开。也可以按 `Ctrl+N` 直接输入任务名称。每次可选择只加入任务列表（`Ctrl+1`）或立即执行（`Ctrl+2`），再按回车保存。立即执行会把当前任务加入待恢复。点击任务行右端的「删除」并确认即可移除任务，已有执行与进展记录会保留。

打开「执行记录」可查看当天执行任务数、完成任务数和总用时。点击或左右拖动「今天／昨天／前天」胶囊切换日期，也可在获得焦点后按方向键切换。用日历选择其他日期。跨午夜的执行按本地日期拆分用时，历史状态按所选日期显示。选中一条记录可查看该任务当天的累计用时，「全部记录」可查看完整执行历史。

升级到支持进展备注的版本前，请先从系统托盘退出旧版，确保同一份任务数据由新版管理。

最小化时，主窗口收进 Windows 系统托盘，桌面自动显示置顶悬浮窗。点击悬浮窗上的「主窗口」或右下角的托盘图标即可恢复。恢复后，自动打开的悬浮窗会收起。悬浮窗的「×」可以单独关闭它，计时与提醒仍在后台运行。主窗口和悬浮窗均显示「下一项待恢复」。穿插任务完成后，点击暖杏色的「恢复任务」开启原任务的一段新计时。「已中断」列表按恢复顺序排列，最近被中断的任务排在最前。

选中任务后点击「在 Web 中查看」，会打开对应日期和编辑表单。「更多」菜单中的「打开 Web 日程」可随时打开日程页面，新建或编辑任务。Web 服务按需启动，只监听本机，并随桌面程序退出。

桌面、Web 和 CLI 默认使用 `%LOCALAPPDATA%\TodoList\tasks.json`。从源码首次启动会在共享任务库尚未建立时读取项目里的旧 `data/tasks.json`。也可以在桌面端点击「导入旧任务…」手动选择这个文件。导入以任务 ID 保留已有任务。旧版「进行中」任务会作为「已中断」导入，可手动继续。可用 `TODO_DATA_FILE` 指定另一份数据文件。

在 Windows 使用 Python 3.12 或更新版本构建。用下面的命令安装打包依赖并生成 `dist/Dashboard/TodoList.exe`。

```powershell
python -m pip install pyinstaller flask python-dateutil windows-toasts PySide6-Essentials
python -m PyInstaller --noconfirm --distpath dist/Dashboard TodoList.spec
```
